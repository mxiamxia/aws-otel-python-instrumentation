## 2025-05-14 - Optimizing OTEL Sampler Matcher
**Learning:** In telemetry processing hot paths like OpenTelemetry samplers, spans often carry a large number of attributes (O(A)) while sampling rules usually only specify a few requirements (O(R)). Iterating over the requirement set (rule attributes) and using early returns provides significant performance gains and predictable O(R) complexity. Additionally, simple wildcard patterns (prefix/suffix/middle) can be matched up to 5x faster using basic string methods compared to full regex matching.
**Action:** Always prioritize requirement-driven iteration (O(R)) over data-driven iteration (O(A)). Implement fast-paths for common wildcard patterns and use `lru_cache` for complex regex fallback to minimize compilation overhead.
