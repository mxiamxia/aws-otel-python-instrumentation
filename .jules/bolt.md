## 2025-05-15 - [Wildcard Matching and Attribute Filtering Optimizations]
**Learning:** Wildcard matching using regex is a significant bottleneck in sampling and attribute filtering. Implementing fast-paths for common patterns like `prefix*`, `*suffix`, and `*middle*` using string methods (`startswith`, `endswith`, `in`) provides a ~5-20x speedup. Additionally, iterating over rule attributes (typically a small set) rather than span attributes (potentially large) in `attribute_match` allows for early returns and better performance. Pre-compiling large regex patterns at the module level avoids redundant compilation and internal cache lookups in hot paths.
**Action:** Always look for fast-path opportunities in string matching logic. Use `lru_cache` for regex compilation of dynamic patterns. Ensure iteration is performed over the smaller set of keys when comparing attribute maps.
